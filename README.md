# 🎮 Guess — Word. Play. Learn.

**A falling-letter puzzle where every block is a chance to make a word.**

Guess combines falling-block mechanics with vocabulary puzzles. Move and rotate pairs of letters as they fall, build words, and clear them from the board. When the stack fills up, switch to a letter-swapping phase and find new words to keep the game going.

🌐 Live Demo: https://guess-r9do.onrender.com

## ✨ Features

- 🧩 **Two-phase gameplay** — stack falling letter pairs, then swap neighbouring letters to discover words.
- 📚 **17,701 English words** — a curated dictionary containing words from 2 to 6 letters.
- 🎯 **Word-based scoring** — longer words earn more points.
- 🌗 **Day and night themes** — switch between two visual styles.
- 🔊 **Spoken words** — hear cleared words using your device's available English voices.
- 🎮 **Keyboard and touch controls** — play with keys, on-screen buttons, or mobile gestures.
- 🏆 **Score and progression** — track your score, high score, level, and words cleared.
- 🛟 **Rescue mechanics** — reshuffle letters when no valid word can be formed.

## 🕹️ How to Play

### Phase 1 — Falling Words

1. Move the falling pair left or right.
2. Rotate the pair to change the order of its letters.
3. Drop letters to build a useful stack.
4. Form valid words using letters on the board to earn points.

A two-letter word gets one extra turn before it clears, giving you a chance to extend it into a longer word.

### Phase 2 — Letter Swapping

When the stack fills up, the game switches to a swapping phase.

- Select a letter and swap it with a neighbouring letter.
- Find valid words to clear letters from the board.
- You have a limited number of swaps, so plan carefully.
- Clear enough letters to bring back the falling blocks.

If no available swap can form a word, the game can reshuffle the letters to help you continue.

## 🎮 Controls

| Key | Action |
|---|---|
| ← / → or A / D | Move the falling pair or cursor |
| ↑ or W | Rotate the pair or move the cursor up |
| ↓ or S | Drop faster or move the cursor down |
| Space / Enter | Rotate or grab a letter |
| P / Esc | Pause the game |
| V | Change the spoken voice |

On mobile, use the on-screen controls and tap or drag neighbouring letters to swap them.

## 🧮 Scoring

Longer words earn more points.

| Word length | Points |
|---|---:|
| 2 letters | 10 |
| 3 letters | 30 |
| 4 letters | 80 |
| 5 letters | 160 |
| 6 letters | 300 |

## 📚 Dictionary and Credits

The main dictionary contains **17,701 unique English words**, each between 2 and 6 letters long. It is derived from SCOWL (Spell Checker Oriented Word Lists) and supplemented with manually reviewed entries.
